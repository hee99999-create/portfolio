PORTRI AI 개인정보처리방침

시행일: 2026년 9월 17일

1. 운영 형태

PORTRI AI는 학회 발표·연구용 데모 서비스입니다. 별도의 회원 데이터베이스를 운영하지 않으며, 이용자가 입력한 정보는 원칙적으로 이용자 본인의 브라우저(localStorage)에만 저장됩니다.

2. 처리하는 개인정보 항목

  • 소셜 로그인(Google·카카오·네이버): 이름(또는 닉네임), 이메일 주소(제공에 동의한 경우).
  • 이메일 로그인: 입력한 이메일 주소와 이름. 비밀번호는 저장하지 않습니다.
  • 이용자가 직접 입력한 내용: 경험 기록, 활동 설명, 성적증명서에서 추출한 과목 정보.

3. 이용 목적

  • 로그인 상태 유지 및 화면에 이름 표시
  • 이용자가 요청한 경험 분석·역량 증거 추출·문서 생성 기능 제공

4. 보관 위치와 기간

로그인 정보와 입력 내용은 이용자 브라우저에 저장됩니다. 로그아웃하면 로그인 정보가 지워지고, 브라우저의 사이트 데이터를 삭제하면 입력한 내용까지 모두 지워집니다. 운영자 서버에는 저장하지 않습니다.

5. 처리 위탁 및 외부 전송

  • OpenAI: AI 분석 기능을 사용할 때, 분석을 요청한 텍스트가 분석 처리를 위해 전송됩니다.
  • Render(백엔드 호스팅): AI 분석 요청과 카카오·네이버 로그인 정보 조회를 중계합니다. 중계한 내용은 저장하지 않으며, 과도한 호출을 막기 위해 IP 주소를 서버 메모리에 일시적으로만 사용합니다.
  • Google·카카오·네이버: 소셜 로그인 인증을 위해 각 서비스로 이동하며, 해당 서비스의 개인정보처리방침이 적용됩니다.

6. 이용자의 권리

이용자는 언제든 로그아웃하거나 브라우저의 사이트 데이터를 삭제해 저장된 정보를 지울 수 있습니다. 소셜 로그인 연결은 각 서비스의 계정 설정(연결된 앱 관리)에서 해제할 수 있습니다.
